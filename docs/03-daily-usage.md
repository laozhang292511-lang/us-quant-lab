# 日常使用方式

## 不需要每次打开 Codex

完成部署后，常规流程由 PowerShell 快捷入口或 Windows 任务计划运行：更新行情、回测、生成信号、模拟交易和输出报告。Codex用于以下情形：

- 用自然语言提出新策略或修改要求
- 解释报告与异常
- 升级软件、修复错误、增加功能
- 在进入模拟或实盘前做审查

## VPN

量化程序本身不以 VPN 为设计依赖。中国大陆网络访问 GitHub、PyPI、Yahoo 数据或海外券商时可能不稳定，应依法依规使用用户已有的合规网络方案。不要把代理账号或配置写入 Git。实盘执行未来优先放在网络稳定的专用主机/VPS，并设置断网保护。

## 你需要学习的重点

- 收益、波动率、最大回撤、夏普比率、换手率的含义
- 过拟合、未来函数、幸存者偏差、样本外与走步验证
- 仓位、相关性、滑点、流动性和极端行情风险
- 如何写清楚策略规则和验收条件
- 如何阅读交易清单、日志、告警与复盘报告
- 嘉信账户权限、订单类型、税务与合规常识

不要求从零学习编程，但要学会识别不可信回测和不合理风险。
