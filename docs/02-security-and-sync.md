# 多电脑同步与安全边界

## 同步什么

- 私有 GitHub 仓库：代码、非敏感配置、文档、策略版本、脱敏摘要报告
- 可选加密存储：必要的个人原始报告；不建议同步完整券商导出
- 不同步：`.env`、OAuth 令牌、API 密钥、完整账户流水、运行锁、原始日志

## 电脑角色

- 电脑 A：完整研究、回测、模拟；未来可临时执行，但默认关闭实盘
- 电脑 B（单位设备）：完整研究、回测、模拟和报告阅读；禁止券商凭据与实盘执行
- 电脑 C/D/E：按设备所有权套用 A 或 B 的安全配置
- 未来 VPS/专用设备：唯一长期实盘执行器

“功能齐全”指软件和界面齐全，不等于每台机器都持有真实账户授权。B 可以生成模拟订单和查看脱敏结果，但风险边界会阻止真实下单。

## 遗失、归还或更换

1. 在 GitHub 撤销该设备的登录会话、SSH key 或细粒度令牌。
2. 若设备曾获券商权限，立即撤销 Schwab 应用令牌并轮换密钥。
3. 从同步/远程访问工具中移除设备。
4. 个人设备启用 BitLocker；单位设备遵循单位管理策略。
5. 交还前删除本地项目、缓存与凭据，并清空回收站；不能自行擦除时由单位 IT 处理。

## 单执行器规则

研究节点可以有多台，实盘执行器同一时间只能有一台。未来使用中央租约锁：执行器定期续租，失去锁立即停止创建新订单。该规则不能只依赖某台电脑上的本地文件锁。
