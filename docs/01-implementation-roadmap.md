# 实施路线

## 阶段 1：本地研究与回测

- 建立隔离的 Python 3.11 环境
- 安装 Vibe-Trading、AgentQuant、Lumibot
- 下载免费行情并缓存到 D 盘
- 实现 ETF 日频只做多策略
- 输出统一中文报告与可复核交易清单

验收条件：同一输入重复运行得到一致结果；报告包含基准、手续费/滑点、最大回撤、换手率和逐笔交易。

## 阶段 2：本地模拟交易

- 每日生成目标持仓和模拟订单
- 风控拒单、熔断、日志和单执行器锁
- A/B 两机共享脱敏报告，只有指定机器可成为执行器
- 连续模拟至少 8–12 周

验收条件：无重复下单，断网/重启可恢复，所有决策可追溯。

## 阶段 3：嘉信接口验证

- 用户申请 Schwab Developer Portal 应用
- 凭据只存于获批准的个人执行主机或 VPS
- 先使用沙盒/最小权限接口验证，再做极小资金试运行
- 单位电脑 B 永远不保存券商凭据

验收条件：人工急停、额度限制、订单核对、令牌更新和故障告警全部通过。

## 阶段 4：正式运行与扩展

- 迁移到低成本 VPS 或专用常开设备
- 增加付费数据、更多策略与组合层
- 保留 A/B/C/D/E 的完整研究能力，但只有一个获授权执行器

首阶段预计软件成本为 0 元；后续 LLM、行情或 VPS 支出必须在 500 元人民币/月预算内单独审批。
