# 美股量化交易母版

这是电脑 A 的量化交易母版工程。目标是让非程序员通过固定入口完成研究、回测、模拟交易和报告复核，并能安全复制到电脑 B/C/D/E。

## 当前阶段

- 首个策略：美股 ETF、日频、只做多、趋势与横截面动量组合
- 初始模拟资金：100,000 美元
- 研究：Vibe-Trading
- 独立验证：AgentQuant
- 确定性回测与未来执行：本工程 + Lumibot
- 实盘券商：Charles Schwab（当前禁用，未配置任何凭据）
- 数据：首阶段使用无需密钥的 Yahoo Finance，并以 Stooq 备用；正式实盘前必须评估付费数据源

## 安全原则

1. Git 只同步代码、配置模板、脱敏报告，不同步密钥、令牌、完整账户流水。
2. 单位电脑 B 可拥有完整研究和模拟功能，但不得保存嘉信凭据或完整账户数据。
3. 实盘默认关闭；只有通过显式审批、风险检查和单执行器锁后才允许启用。
4. AI 负责研究和生成候选方案，确定性程序负责风险检查与下单。
5. 任一回测结果都不等于未来收益承诺。

## 目录

```text
config/       非敏感配置与模板
data/         本地数据（不进入 Git）
docs/         架构、安全、部署与操作说明
reports/      可同步的脱敏报告
runtime/      锁、日志和运行状态（不进入 Git）
scripts/      面向用户的一键入口
src/          策略、回测和风控代码
tests/        自动验收测试
vendor/       外部开源项目源码（不进入本仓库）
```

## 当前可用入口

环境安装完成后，日常操作通过 `scripts` 目录中的 PowerShell 入口完成，不要求每次打开 Codex。Codex主要用于搭建、修改策略、排障和解释报告。

详细状态见 [电脑 A 预检报告](docs/00-computer-a-preflight.md) 与 [实施路线](docs/01-implementation-roadmap.md)。
